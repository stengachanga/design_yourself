## Context

Лендинг уже опубликован на GitHub Pages. Заказчик предоставил финальные вводные:
- текст: `Site description.txt`
- визуальный лейбл: `Label.jpg` («Собери Себя Сам», силуэт из пазлов)
- фото: `Psychologist.jpg`

Позиционирование: **индивидуальное психологическое консультирование** (миссия «Конструктор личности»), методы КПТ, гештальт, коучинг. Не курсы и не «волшебные» обещания.

## Goals / Non-Goals

**Goals:**
- Соответствие текста site description
- Бренд и палитра по label
- Реальное фото вместо иллюстраций
- CTA: запись на консультацию
- Сохранить Метрику, форму, Pages deploy

**Non-Goals:**
- Каталог курсов и прайс-лист как основной оффер
- Иллюстрации с животными
- Смена счётчика Метрики / репозитория

## Decisions

### 1. Бренд и копирайт

**Решение:** Название бренда на сайте — «Собери Себя Сам». Миссия/слоган — «Конструктор личности». Цель формулируется как «не пересобрать, а структурировать».

### 2. Цветовая схема (из Label.jpg)

| Роль | Hex | Источник |
|------|-----|----------|
| `--color-navy` | `#203850` | тёмные куски пазла / обводка |
| `--color-teal` | `#488088` | средние куски пазла |
| `--color-teal-dark` | `#306070` | hover / secondary |
| `--color-accent` | `#D07840` | оранжевые куски пазла — primary CTA |
| `--color-accent-dark` | `#B85830` | CTA hover |
| `--color-bg` | `#F4F4EF` | светлый фон label |
| `--color-bg-alt` | `#E8E8E0` | чередование секций |
| `--color-surface` | `#FFFFFF` | карточки / форма |
| `--color-text` | `#1A1A1A` | текст логотипа |
| `--color-text-muted` | `#5A6068` | вторичный текст |

**Типографика:** выразительный sans для заголовков (совпадает с геометричным шрифтом label) + читаемый body sans. Избегать Inter/Roboto/Arial как единственного стека — использовать `Manrope` + `Source Sans 3` (или аналог).

### 3. Структура секций

1. Hero — label + миссия + CTA + фото психолога (full-bleed / доминантный visual)
2. Подход — «не пересобрать, а структурировать» + методы
3. О специалисте — образование МИП, опыт 8+8+8
4. Принципы — красные «не делаю» / зелёные «использую»
5. Гарантии — безопасность, прозрачность сеттинга, конфиденциальность
6. Результат — «что вы получите»
7. Запись — форма + CTA

### 4. Ассеты

- Logo / favicon / og:image fallback: `assets/images/label.jpg`
- Hero / about photo: `assets/images/psychologist.jpg`

### 5. Аналитика и форма

Без смены счётчика `110553308`. Цели CTA сохраняются по смыслу (клик записи / submit). Telegram по-прежнему через `config.js`.

## Risks / Trade-offs

| Риск | Митигация |
|------|-----------|
| Старые URL/OG с курсами | Обновить title/description/JSON-LD |
| Оранжевый CTA на светлом фоне — контраст | Проверить WCAG AA; hover `#B85830` |
| Смена оффера ломает ожидания старых посетителей | Чёткий H1 и CTA «консультация» |
