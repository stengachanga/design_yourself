## Context

Лендинг на GitHub Pages. Бренд/миссия: «Конструктор Личности». Запись и сервисы клиента — через Telegram-бота; лендинг знакомит с подходом и ведёт в бота.

## Goals / Non-Goals

**Goals:**
- Лендинг без веб-формы: CTA → Telegram-бот
- Бот: запись, вопрос, оплата сеанса; пересылка психологу
- Соответствие Site description / палитра label
- OpenSpec: `landing-page` + `telegram-bot`

**Non-Goals:**
- Встроенная платёжная эквайринг-интеграция (пока ссылка/реквизиты из env)
- Токен бота в публичном `config.js`
- Каталог курсов

## Decisions

### 1. Бренд в шапке
Wordmark шапки: «Конструктор Личности». Hero: «Задача: не пересобрать, а структурировать».

### 2. Канал записи
Все заявки и сообщения клиента идут через бота `@soberi_sebya_sam_bot`. Психолог получает пересылки в `TELEGRAM_CHAT_ID`.

### 3. Функции бота
Клавиатура: Записаться / Задать вопрос / Оплатить сеанс (+ опционально О подходе).
Оплата: `TELEGRAM_PAYMENT_URL` и/или `TELEGRAM_PAYMENT_DETAILS` в `bot/.env`.

### 4. Лендинг
Секция контакта — только переход в бота. Sticky/hero CTA открывают бота.

### 5. Деплой
Pages публикует статику без инъекции bot token. Бот хостится отдельно (polling).

## Risks / Trade-offs

| Риск | Митигация |
|------|-----------|
| Бот не запущен — заявки не доходят | README + мониторинг хостинга |
| Токен в истории git | Только `.env` / secrets хоста; revoke при утечке |
| Нет эквайринга | Явные реквизиты/ссылка + уведомление психологу |
