## Design Review
**Score:** 6.5/10

### Critical
- CTA `#d07840` + белый текст ≈ **3.26:1** — ниже WCAG AA (4.5:1); hover проходит, дефолт — нет
- Бренд раздвоен: хедер «Конструктор Личности», label — «Собери Себя Сам»
- Одно фото в hero и «О специалисте»

### Recommendations
- Затемнить акцент CTA до AA (≥4.5:1)
- Один primary brand + mark без конкурирующего текста в hero
- Второй кадр для about; принципы не оставлять одинокой карточкой
- Лёгкий serif для H1/H2 опционально; `:active` и `prefers-reduced-motion`

### Quick wins
- Починить contrast accent; уменьшить/убрать повтор label в hero
- Воздух между approach и about; почистить мёртвый CSS (ghost/form)

## SEO Review

## Psychologist Review
**Score:** 5/10

### Critical
- «Устойчивый результат без отката» звучит как гарантия исхода
- «Абсолютная конфиденциальность» юридически/этически неверна (+ Telegram ≠ клиника)
- Нет имени; образование без типа документа; 8+8+8 — опыт *до* практики
- «Научно доказанные» для КПТ+гештальт+коучинг — смешение силы доказательности
- Оплата в боте без цены/условий/возвратов

### Recommendations
- Развести консультирование vs психотерапия/медицина
- Уточнить документ об образовании; смягчить формулировки гештальта
- Кризис: 112 / телефон доверия + в `/start` бота
- Согласие и политика до сбора контактов и оплаты

### Quick wins
- «Гарантии» → «Принципы работы»; убрать «абсолютная»
- Смягчить блок результата; сузить «научно доказанные»
- Починить privacy; вернуть анти-позиционирование из брифа; оплата только после согласования

## Telegram Bot Review
**Score:** 6/10

### Critical
- Два poller’а → `409 Conflict` и тишина
- Сессии только в памяти — рестарт рвёт диалог
- Нет ответа психолога клиенту через бота
- Фото/caption оплаты не обрабатываются
- HTML без escape; deep links `?start=` не поддержаны

### Recommendations
- Один инстанс / webhook + healthcheck
- Persist sessions + TTL
- Reply-from-admin; приём фото оплаты; Invoice или явный URL
- Deep links book|ask|pay с сайта

### Quick wins
- Парсить `/start book`; `escapeHtml`; `caption||text`; ссылка на клиента в notify; не гонять два `npm start`

## Marketing Review
**Score:** 5/10

### Critical
- Два бренда одновременно — ломают запоминание и атрибуцию рекламы
- Нет упаковки оффера: цена, длительность, онлайн/офлайн
- Value prop абстрактный без болей ЦА
- Trust-дыра: нет имени, отзывов, реального контакта
- Воронка сайт→бот с трением; цели Метрики смешаны (sticky = hero)

### Recommendations
- Один master-бренд + подзаголовок
- Блок «Формат и стоимость» над сгибом / у CTA
- H1 под результат ЦА + чипы запросов с префиллом в бот
- ФИО, отзывы, анти-позиционирование из брифа
- Развести goals; lead-magnet / ретаргет

### Quick wins
- Унифицировать бренд в header/footer/title/og
- Prefill Telegram + `start=site|book`
- Имя рядом с CTA; единая формулировка кнопки
- Вернуть «не таблетка / не трансерфинг» на лендинг
