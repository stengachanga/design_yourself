## 1. UX Mobile — 8.0/10

### Исправлено ✓
- Sticky CTA «Записаться» внизу экрана после скролла hero
- `scroll-padding-top` — якоря не перекрываются header
- Блокировка скролла body при открытом меню + Escape
- Переключатель телефон / email с корректными `inputmode`
- Уменьшены отступы секций на `<768px`
- Skip-link для screen readers

### Остаётся улучшить
- **Форма всё ещё внизу** — sticky CTA частично компенсирует, но mid-page форма или modal повысит конверсию с рекламы
- **Hero-изображение** на mobile занимает много места до CTA — рассмотреть `order: -1` только на desktop или уменьшить высоту img
- **4 колонки карточек → 1** — длинный скролл; accordion или табы для курсов на mobile
- **Sticky CTA** не виден в desktop snapshot — проверить на реальном 375px (работает через IntersectionObserver)

### Quick wins
- Добавить `loading="lazy"` на hero только для desktop (сейчас `eager` — ok для LCP)
- Кнопка «Позвонить» появится после заполнения `contactPhone` в config

## 2. UX Web — 8.5/10

### Исправлено ✓
- Единый бренд **Design Yourself** (logo, title, footer)
- Таблица сравнения программ
- Mid-page CTA «Получить консultation»
- Pre-fill курса из карточки (`data-course`)
- Шаги записи 1→4
- Hover на карточках, highlight секции courses
- Footer: политика, оферта, email
- Telegram скрыт до config (не показывает «скорo»)

### Остаётся улучшить
- **Отправка заявки через mailto** — на desktop без настроенного почтового клиента UX ломается; приоритет Formspree
- **Placeholder email** `hello@design-yourself.example` в footer и контактах — снижает доверие
- **Нет активного пункта навигации** при скролле (optional scroll-spy)
- **Сравнительная таблица** на mobile требует горизонтальный скролл — ok, но можно добавить hint «листайте →»

### Quick wins
- Заполнить `config.js` реальными контактами
- UTM-параметры в CTA для рекламных кампаний (`?utm_source=vk`)

## 3. SEO — 8.0/10

### Исправлено ✓
- Абсолютные `canonical`, `og:url`, `og:image`
- Twitter Card
- JSON-LD: Organization, Course ×3, FAQPage
- `robots.txt` + `sitemap.xml`
- Title с ключевыми словами «онлайн», «супервизия»
- Apple touch icon

### Остаётся улучшить
- **FAQ schema неполный** — в разметке 3 вопроса, на странице 8. Google может не показать все rich snippets
- **4-й курс (супервизия)** отсутствует в Course schema
- **hero.png** вероятно >500 KB — медленный LCP; нужен WebP + сжатие
- **Organization email** в schema — placeholder `.example`
- **Нет `hreflang`** — ok для одноязычного RU-сайта
- **Google Fonts** render-blocking — self-host или `media="print" onload` trick

### Quick wins
- Добавить все 8 FAQ в JSON-LD (copy-paste из HTML)
- Добавить Course для супервизии
- Сжать og:image до 1200×630, <200 KB

## 4. Design — 8.0/10

### Исправлено ✓
- Logo с иконкой-совой
- Иконки-символы в блоке преимуществ
- Аватары-инициалы в отзывах (МК, АВ)
- Отдельное изображение `team.png` для преподавателей
- `:focus-visible` на интерактивных элементах
- Equal-height карточки + hover lift
- Steps indicator, section highlight animation
- Спокойная палитра сохранена

### Остаётся улучшить
- **Иллюстрации с животными** — запоминаются, но для переподготовки часть ЦА воспринимает несерьёзно; гибрид: реальные фото + одна иллюстрация в hero
- **Unicode-иконки** (◉◎◇○) — заменить на SVG для единообразия
- **Badge «Популярный»** — на узких экранах ok благодаря `padding-right` на h3, но проверить 320px
- **Нет тёмной темы** — не критично

### Quick wins
- SVG-иконки для benefits (16×16, stroke currentColor)
- Favicon `.ico` 32+16 для старых браузеров

## 5. Psychologist — 8.5/10

### Исправлено ✓
- Блок «Для кого / Не подойдёт»
- Этический дисклеймер (не заменяет мед. помощь)
- EAGT, ВООПИГ по имени вместо «международной аккредитации»
- FAQ: личная терапия, супервизия, статус в РФ, противопоказания
- «Не является публичной офертой»
- Чекбокс согласия на ПДн + `privacy.html`
- Отзывы с программой и городом
- Тон отзывов смягчён («лучше понимаю» vs «наконец поняла»)

### Остаётся улучшить
- **Отзывы без верификации** — инициалы ok, но для рекламы лучше реальные (с согласием) или убрать фамилии
- **Claim «согласована с ВООПИГ, EAGT»** — нужна ссылка на конкретную программу/лицензию или формулировка «ориентируемся на стандарты»
- **Профстандарт «Педагог-психолог»** — уточнить номер/регистрацию или смягчить до «соответствует требованиям доп. проф. образования»
- **152-ФЗ:** политика есть, но оператор с `.example` email — заменить на реальный

### Quick wins
- Добавить строку «Программы не являются медицинской услугой» в footer
- Ссылка на кодекс этики ВООПИГ
