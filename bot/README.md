# Telegram-бот «Конструктор Личности»

Сайт **продаёт** оффер. Бот **привлекает**: вопрос, запись, объяснение первой встречи, оплата после согласования.

## Меню

- Записаться
- Задать вопрос (низкий порог)
- Что будет на встрече
- Оплатить сеанс

Админ отвечает клиенту: **reply** на пересылку или `/reply CHAT_ID текст`.

Только **один** инстанс `npm start`.

```bash
cd bot
cp .env.example .env
npm install
npm start
```
