## Design Review
**Score:** 6.5/10

### Critical
- CTA `#d07840` + белый текст ≈ **3.26:1** — ниже WCAG AA (4.5:1); hover проходит, дефолт — нет
- Бренд раздвоен: хедер «Конструктор Личности», label — «Собери Себя Сам»
- Одно фото в hero и «О специалисте»

### Recommendations
- Затемнить акцент CTA до AA (≥4.5:1)
- Один primary brand + mark без конкурирующего текста в hero
- Второй кадр для about; принципы не оставлять одинокой карточкой
- Лёгкий serif для H1/H2 опционально; `:active` и `prefers-reduced-motion`

### Quick wins
- Починить contrast accent; уменьшить/убрать повтор label в hero
- Воздух между approach и about; почистить мёртвый CSS (ghost/form)

## Psychologist Review
**Score:** 5/10

### Critical
- «Устойчивый результат без отката» звучит как гарантия исхода
- «Абсолютная конфиденциальность» юридически/этически неверна (+ Telegram ≠ клиника)
- Нет имени; образование без типа документа; 8+8+8 — опыт *до* практики
- «Научно доказанные» для КПТ+гештальт+коучинг — смешение силы доказательности
- Оплата в боте без цены/условий/возвратов

### Recommendations
- Развести консультирование vs психотерапия/медицина
- Уточнить документ об образовании; смягчить формулировки гештальта
- Кризис: 112 / телефон доверия + в `/start` бота
- Согласие и политика до сбора контактов и оплаты

### Quick wins
- «Гарантии» → «Принципы работы»; убрать «абсолютная»
- Смягчить блок результата; сузить «научно доказанные»
- Починить privacy; вернуть анти-позиционирование из брифа; оплата только после согласования

## AppSec Review

**Score:** 7.5/10

### Critical
- Критичных дыр на текущей публичной поверхности (Pages + `js/config.js`) не видно: токен бота на фронте отсутствует, в деплой не инжектится, `bot/.env` в `.gitignore`.
- **Операционный риск:** в истории репозитория есть коммиты про удаление token / hardcode `chat_id` с фронта. Если реальный токен когда-либо попадал в публичный git — **немедленно ротировать** `TELEGRAM_BOT_TOKEN` у @BotFather (значения здесь не приводятся).

### Recommendations
- **Flood / abuse:** любой текст/медиа вне сессии уходит админу без rate limit (`notifyAdmin` + `copyMessage`). Добавить лимит (N сообщений / минуту на `chat_id`) и отказ с вежливым ответом.
- **Медиа:** `copyMessage` принимает любой `photo`/`document`. Ограничить типами (jpeg/png) и/или размером; иначе админа можно заспамить тяжёлыми файлами.
- **Multi-poller:** предупреждение в README есть, но нет webhook/lock. На хостинге зафиксировать один процесс (healthcheck / запрет второго `npm start`), иначе `409 Conflict` и потеря апдейтов.
- **Defense-in-depth HTML:** `PRIVACY_URL` вставляется в `parse_mode: HTML` без `escapeHtml` (welcome / book). Экранировать env-строки так же, как `PAYMENT_*`.
- **Privacy vs факт:** политика упоминает «форму связи на Сайте», на лендинге формы нет — только Telegram + Метрика/Webvisor. Синхронизировать текст.
- **Lockfile:** `bot/package-lock.json` есть локально, но не в git (по статусу) — закоммитить для воспроизводимых зависимостей.
- **История секретов:** после ротации проверить, что старый токен не остаётся в зеркалах/форках; при необходимости `git filter-repo` / BFG (отдельная задача).

### Quick wins
- Экранировать `PRIVACY_URL` через `escapeHtml`.
- Rate limit на свободные сообщения и pay/ask completion.
- В privacy.html убрать/исправить формулировку про форму на сайте.
- Закоммитить `bot/package-lock.json`; убедиться, что `bot/.env` никогда не попадает в артефакты деплоя (сейчас не копируется — ок).
- При любом сомнении по утечке — ротация токена + смена `TELEGRAM_CHAT_ID` не нужна, достаточно токена.
